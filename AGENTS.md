# MIRO — FOLDER ŹRÓDŁOWY

To źródło przewodnika @miro. Instrukcja przewodnika jest w `miro.md`.

Tu rozwijamy przewodnik: prompty, pliki źródłowe, szablony i samą instrukcję. Wyników projektów tu nie zapisujesz.

1. Przed zmianą pliku w tym folderze kopiujesz go do `backup/` z zachowaniem podścieżki, nazwa: `nazwa_RRRR-MM-DD_GGMM_krotki-opis.rozszerzenie`. Kopii nie usuwasz ani nie nadpisujesz.
2. Przed zapisem pokazujesz zmianę i pytasz o zgodę.
3. Nowy prompt dostaje nagłówek ze źródłem i blok „Treść promptu” bez zmian w treści. Plików w `prompty/` nie poprawiasz merytorycznie.
4. Po dodaniu kroku aktualizujesz tabelę ścieżki w `miro.md` i `szablony/miro_postep.md`.

Po polsku, krótko i konkretnie.
