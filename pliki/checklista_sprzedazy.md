Zasady:
1. To jest materiał referencyjny, nie skrypt do kopiowania 1:1.
2. CSO ma dobierać techniki do ceny, relacji, etapu zaufania i danych z projektu.
3. Tanie oferty można prowadzić szybciej.
4. Drogie oferty zwykle wymagają procesu: diagnoza, zaufanie, wartość, rozmowa, oferta, follow up, domknięcie.
5. Nie używaj fałszywej pilności, wymyślonego social proofu ani presji bez wartości.

## TECHNIKI ZAMYKANIA

### Fundamentalna zasada

Każda odpowiedź musi prowadzić rozmowę do następnego sensownego kroku.
Nie zawsze jest nim zakup od razu.
Czasem jest nim diagnoza, rozmowa, dosłanie oferty, follow up albo decyzja, że lead nie pasuje.

### 7 technik closerskich

#### 1. ASSUMPTIVE CLOSE (zakładasz że kupuje)

```
"Raty czy jednorazowo?"
"Który termin Ci pasuje - 15 czy 22 listopada?"
"Faktura na firmę czy prywatnie?"
"Zobaczymy się na starcie?"
```

ŹLE: "Pytaj jeśli coś" (zostawia bez akcji)
DOBRZE: "Raty czy jednorazowo?" (zakłada że kupuje)

#### 2. URGENCY CLOSE (deadline = akcja)

```
"Start za 5 dni, zostało 3 miejsca"
"Cena rośnie 10 listopada (zostało 48h)"
"Early bird kończy się dziś o 23:59"
"Zapiszesz się dziś? Jutro cena +500 PLN"
```

#### 3. FOMO CLOSE (strach że przegapi)

```
"5 miejsc zostało (z 20 było)"
"To ostatni termin w tym roku"
"Kto wcześniej zapisze, ten wejdzie - nie ma listy rezerwowej"
```

#### 4. ROI CLOSE (pokaż co zyskuje vs co traci)

```
"Rok bez [NAZWA OFERTY]: [koszt braku decyzji]. Rok z [NAZWA OFERTY]: [realny zysk albo oszczędność]. Co wybierasz?"
"3000 PLN teraz = 30,000 PLN w 5 lat (z jednego produktu)"
"Co bardziej boli - wydać 3k dziś czy nie zarobić 30k?"
"Jeden klient zwróci Ci koszt programu. Reszta = zysk."
```

#### 5. SOCIAL PROOF CLOSE (inni kupili = bezpiecznie)

```
"[konkretny procent z Twoich danych] klientów osiąga [konkretny wynik]"
"[imię klienta] osiągnął [konkretny wynik] w [konkretnym czasie]"
"Zobacz opinie: [link]"
"Społeczność [liczba] klientów daje regularny feedback: [konkretny cytat albo wniosek]"
```

#### 6. BONUS CLOSE (dostanie więcej za szybka decyzje)

```
"Zapiszesz się dziś do 18:00? Dostajesz bonus: [X]"
"Pierwsze 10 osób dostaje: [extra wartość]"
"Early bird = cena niższa + bonus [X]"
```

#### 7. P.S. CLOSE (ostatni push po głównej wiadomości)

```
"P.S. Cena rośnie za 3 dni."
"P.S. Zostało 4 miejsca."
"P.S. [imię klienta] osiągnął [konkretny wynik] w [konkretnym czasie]."
"P.S. Bonus kończy się dziś o północy."
```

### Jak kombinować techniki

Przykład: Pytanie o cenę - 6 technik w jednej odpowiedzi:

```
Cześć Anno!

[CENA + REFRAME] [NAZWA OFERTY] = [cena] PLN ([wartość w tygodniu albo miesiącu]).

[ROI CLOSE] Jeden klient zwróci Ci ten koszt. Reszta = zysk.

[URGENCY + FOMO] Start za 5 dni, zostały 3 miejsca, jeśli to prawdziwy limit.

[SOCIAL PROOF] [konkretny dowód z Twoich danych albo opinii klienta].

[ASSUMPTIVE CLOSE] Raty czy jednorazowo?

Link: [url]

[P.S. CLOSE] P.S. Cena rośnie 10.11 (zostało 48h na obecną cenę).

M
```

### Elementy sprzedażowe

| Element | Kiedy | Przykłady |
|---------|-------|-----------|
| Social proof | Gdy pasuje | "[konkretny wynik klienta]", "[prawdziwy dowód z opinii albo danych]" |
| Urgency | Gdy prawdziwe | "Zostało 3 miejsca", "Cena rośnie 10 listopada" |
| Value proposition | Zawsze | Co dokładnie dostanie, jaki problem rozwiązuje, jaka wartość daje |
| Derisking | Gdy obiekcja | "14 dni gwarancji zwrotu", "Nagrania na zawsze", "Raty 0%" |

### Mentalnosc closera

3 ZASADY:

**1. KAŻDY MAIL = OKAZJA DO SPRZEDAŻY**
- Pytanie o cenę? --> Zamknij sprzedaż
- Pytanie techniczne? --> Odpowiedź + zamknij sprzedaż
- Obiekcja? --> Rozbij + zamknij sprzedaż
- NIE MA sytuacji gdzie nie próbujesz zamknąć

**2. "PYTAJ JEŚLI COS" = PORAŻKA**
- ŹLE: "Oto info. Pytaj jeśli coś."
- DOBRZE: "Oto info. Raty czy jednorazowo? Link: [url]"
- Nigdy nie zostawiaj bez CTA + trial close

**3. MYŚL JAK CLOSER, NIE JAK HELPER**

| Helper | Closer |
|--------|--------|
| "Odpowiedzialem, koniec" | "Odpowiedzialem, teraz dopnę sprzedaż" |
| "[NAZWA OFERTY] kosztuje [cena]. Pytaj jeśli coś." | "[NAZWA OFERTY] = [cena]. Jeden klient może zwrócić Ci koszt, jeśli to wynika z Twojej ekonomii. Start [data], zostało [liczba] miejsc, jeśli to prawdziwy limit. Raty czy jednorazowo? Link: [url]" |

### Pamietaj

- Każda odpowiedź bez następnego kroku = zmarnowana okazja
- Pilnosc stosuj tylko wtedy, gdy jest prawdziwa
- P.S. stosuj tylko wtedy, gdy naturalnie wzmacnia odpowiedź
- Każda odpowiedź BEZ stylu z ghost.md = nie brzmi jak TY

## OBSŁUGA OBIEKCJI

### Filozofia

Obiekcje to PROBLEMY DO ROZWIAZANIA, nie przeszkody.
Obiekcje rzadko są "czyste" - zwykle to mieszanka dwoch typow.
Twoja robota: zidentyfikowac PRAWDZIWY powód i poprowadzic klienta do właściwej decyzji.

### Matryca obiekcji

```
                 LOGISTYCZNA          STRACH          SMOKESCREEN
              ----------------------------------------------------->

PIENIADZE    | Logistyczna+Pieniadze | Strach+Pieniadze |
             | (jak zaplacic)        | (czy warto)      |
             |                       |                  |
"MUSZE       | Logistyczna+Przemyslec| Strach+Przemyslec|  SMOKESCREEN
PRZEMYŚLEĆ"  | (timing, jak)         | (boję się)       |  (fałszywe
             |                       |                  |   obiekcję)
PARTNER      | Logistyczna+Partner   | Strach+Partner   |
             | (partner kontroluje   | (partner się     |
             |  finanse)             |  nie zgodzi)     |
```

### 6 typow obiekcji

| Typ | Co to znaczy | Jak rozpoznac |
|-----|--------------|---------------|
| STRACH | Boi się decyzji, porazki, zmiany | "Nie wiem czy dam rade", "A co jeśli nie zadziała" |
| LOGISTYCZNA | Problem z RUCHEM pieniędzy (nie z ich brakiem) | "Muszę przeniesc z oszczędności", "Czekam na przelew" |
| PIENIADZE | Brak wartości (ROI) LUB brak środków | "Za drogo", "Nie stac mnie" |
| PARTNER | Potrzebuje zgody partnera/malzonka | "Muszę pogadac z zona/mezem" |
| "MUSZE PRZEMYŚLEĆ" | Ukrywa inna obiekcję (zwykle strach lub pieniądze) | "Dam znac", "Muszę to przemyśleć" |
| SMOKESCREEN | Fałszywe obiekcje - nie ma potrzeby/chęci | Ciągle wymówki, każda odpowiedź generuje nową obiekcje |

### Obiekcja: PARTNER ("Muszę pogadac z zona/mezem")

**KROK 1: Ustaw się po tej samej stronie**

```
"Okej, rozumiem. Gdyby Twój partner byl tutaj teraz i byl za -
czy to byloby rozwiązanie dla Ciebie?

[TAK]

Okej. Ale DLACZEGO? Co konkretnie daje Ci największą wartość?

[odpowiedź]

Okej. A jak Twój partner patrzy na to, że zdobywasz umiejętności
żeby Wasz biznes zrobił [CEL] PLN w najbliższych 12 miesiącach?

[odpowiedź]

No właśnie. A co zrobisz jeśli partner NIE CHCE żebyś zainwestował
w program który da Ci te umiejętności?

[odpowiedź]

No właśnie - jak osiagniesz [CEL] bez tych umiejętności?"
```

**KROK 2: Czy partner jest na pokladzie?**

| Scenariusz | Co robic |
|------------|----------|
| Partner NIE jest za, ale klient CHCE | --> Soft close + obsłuż kolejne obiekcję (to strach) |
| Partner NIE jest za i klient NIE ruszy | --> Open Wallet Test |

**KROK 3: Open Wallet Test**

```
"Okej, mamy dwie opcję.

Opcja 1: Umawiamy follow-up kiedy porozmawiasz z partnerem.

Opcja 2: Zostawiasz dane karty TERAZ. Nie po to żeby 'rezerwować miejsce'
czy coś takiego - to nie o to chodzi.

Robimy to jako EMOCJONALNE ZOBOWIAZANIE wobec Twojego celu.

Zauwazylismy że kiedy idziesz do partnera z jakas forma zobowiazania -
ale jednocześnie szanujesz go na tyle żeby dać mu udział w decyzji -
to przychodzisz z PEWNOŚCIĄ i ZAANGAŻOWANIEM które jest widoczne.

Jak chcesz to rozegrać? Co sprawi że dziś wieczorem położysz się spać
wiedząc że robisz wszystko żeby osiągnąć [CEL]?"
```

**KROK 4: Jeśli dalej nie chce --> Follow-up z partnerem**

### Obiekcja: PIENIADZE ("Za drogo" / "Nie stac mnie")

**KROK 1: Niech SAM wymysli rozwiązanie**

```
"Powiedz mi - gdybys MIAL te środki, czy to byloby rozwiązanie dla Ciebie?

[Wiekszosc powie TAK]

Okej, ale DLACZEGO tak uważasz?

[odpowiedź - tu słuchasz co jest dla niego wartością]

Rozumiem. Widze że pieniądze mogą być problemem.
Jak myslisz - jak możesz to rozwiązać?
Skąd możesz wziac środki żeby zdobyc umiejętności
które pozwola Ci dojsc do [CEL]?"
```

**KROK 2: Niech sam znajdzie rozwiązanie**

Jeśli nie wie:
```
"Jakie inne opcję masz żeby znalezc środki na rozwoj biznesu do [CEL] PLN?"
```

**KROK 3: Zaszczep idee kredytu/rat**

Jeśli dalej nie wie:
```
"Czy rozwazales żeby wziac to na karte kredytowa albo raty
i spłacić z dodatkowych zyskow które wygenerujesz dzięki programowi?"
```

**KROK 4: Decyzja**

| Scenariusz | Co robic |
|------------|----------|
| Zgadza się na opcję finansowania | --> Przejdz do obiekcji STRACH (bo to ona blokuje) |
| Nie chce zadnej opcji | --> Zaproponuj konkretne opcję finansowania |
| Dalej nie chce | --> To pewnie SMOKESCREEN |

### Obiekcja: STRACH (3 Reframe'y)

Cel: ZMIANA PERSPEKTYWY. Nie przekonujesz - pomagasz zobaczyć inaczej.

**REFRAME #1: Zmiana procesu decyzyjnego**

```
Ty: "Rozumiem że to duza decyzja i że potrzebujesz czasu.
     Mogę o coś zapytać? Czy uważasz że Twój MINDSET wplywa
     na Twoje decyzje?"

Klient: "Tak, pewnie."

Ty: "Okej. I czy jestes w 100% zadowolony z tego gdzie teraz jestes
     z [biznesem/zarobkami/umiejętnościami]?"

Klient: "No... nie."

Ty: "Rozumiem. I czy chcesz żeby TEN SPOSOB podejmowania decyzji
     dyktowal Twoje wyniki w przyszlosci?"

Klient: "Nie, nie chce."

Ty: "Dlaczego nie?"

[Tu klient SAM sobie tłumaczy dlaczego musi zmienić podejście]
```

**REFRAME #2: Analogia wyspy**

```
"Moze wytlumacze to inaczej.

Wyobraz sobie że jestes na wyspie otoczonej woda.
Mieszkasz tam, pracujesz tam. Wszystko co widzisz wokół
to 30 km w każdym kierunku - i wszedzie woda.

WSZYSTKIE Twoje decyzje podejmujesz z ta perspektywa.
Perspektywa która masz KSZTALTUJE Twoje decyzje.

Ale żeby zobaczyć świat jaki NAPRAWDE jest - musisz być na szczycie góry.

Najtrudniejsze jest:
1. Najpierw UWIERZYĆ że góra w ogóle istnieje
2. Potem wybrac kierunek i ZACZAC ISC

Chodzilismy po wyspie już jakis czas.
Moze pora wybrac kierunek, zalozyc buty i zacząć podejmowac decyzje
jak ktos kto JEST JUŻ NA GORZE.

Co musisz zrobić żeby postawic się w najlepszej pozycji
do osiagniecia tego czego chcesz?"
```

**REFRAME #3: Analogia zmiany perspektywy**

```
"Wszyscy podejmujemy decyzje w oparciu o nasza perspektywe.

Ale najtrudniej jest podejmowac decyzje w oparciu o to
GDZIE CHCEMY BYC, nie gdzie jestesmy.

Osoba z nadwaga ma nadwage tylko dlatego że PODEJMUJE DECYZJE
jakie podejmuje osoba z nadwaga.

Ma fundamentalnie wadliwy proces decyzyjny
dotyczący zdrowia, fitnessu i odżywiania.

Dopiero kiedy ZACZNIE podejmowac decyzje jak osoba zdrowa i wysportowana -
STANIE SIĘ osoba zdrowa i wysportowana.

Rozumiesz o co mi chodzi?

Jakie decyzje musisz zacząć podejmowac żeby miec perspektywe
która CHCESZ miec?"
```

### Obiekcja: SMOKESCREEN (Fałszywe obiekcje)

**Jak rozpoznac:**
- Każda Twoja odpowiedź generuje NOWA obiekcję
- Obiekcje są niespojna lub się wykluczaja
- Brak prawdziwej potrzeby lub pragnienia

**Co robic:**
```
"Hej, mam wrazenie że coś Ci nie gra ale nie do konca to artykulujesz.
Powiedz mi szczerze - czy to jest w ogóle coś czego potrzebujesz?
Czy może po prostu teraz nie jest na to czas?

Wolę żebyś mi powiedział wprost niz żebyśmy obaj tracili czas."
```

Prawda: W smokescreenach NIE MA wygranej. Lepiej to zidentyfikowac wczesnie i nie tracic energii.

### 10 krokow obsługi obiekcji - uniwersalny proces

**KROK 1: ZIGNORUJ (jeśli możesz)**
Wiekszosc obiekcji to AUTOMATYCZNE reakcje. Nie są prawdziwe.
--> Kontynuuj prezentacje jakby nic się nie stalo.
--> Jeśli wraca --> przejdź do kroku 2.

**KROK 2: WYSLUCHAJ DO KONCA**
Pozwol im się wypowiedziec. NIE PRZERYWAJ.
--> Sluchaj aktywnie (potakuj, kontakt wzrokowy).
--> Pokaz że naprawde slyszysz.

**KROK 3: POWTORZ (Feedback)**
```
"Czyli rozumiem że [powtórz obiekcję własnymi słowami]?"
```
--> Upewnij się że dobrze rozumiesz.
--> Oni czuja się wysluchani.

**KROK 4: ZAKWESTIONUJ**
```
"Mogę zapytać - dlaczego tak uważasz?"
"Co sprawia że tak myslisz?"
```
--> Znajdź PRAWDZIWY powód (czesto ukryty).

**KROK 5: AS IF FRAME + TEST CLOSE**
```
"Gdybysmy rozwiazali [obiekcję] - czy bylbys gotowy isc dalej?"
"Jeśli mogę pokazać że [rozwiązanie] - możemy działać?"
```
--> Sprawdz czy to OSTATNIA obiekcja.
--> Jeśli "ale..." --> wróć do kroku 4.

**KROK 6: ALIGNMENT FRAME (Zgoda)**
```
"Rozumiem dokładnie o co Ci chodzi..."
"Czuje to samo co Ty..."
"Wielu klientów mowilo mi to samo..."
```
--> NIGDY nie klocz się!
--> Ustaw się po tej samej stronie.

**KROK 7: ZAMIEN OBIEKCJE W PYTANIE**
```
Obiekcja: "Za drogo"
Pytanie: "Jak możemy sprawic żeby to mialo sens finansowy?"

Obiekcja: "Nie mam czasu"
Pytanie: "Jak możemy to dopasowac do Twojego harmonogramu?"
```
--> Teraz WSPOLNIE szukacie rozwiązania.

**KROK 8: ODPOWIEDZ (3 metody)**

WHY (Dlaczego):
```
"Wlasnie dlatego powinieneś to zrobić TERAZ..."
"To jest dokładnie powód dla którego..."
```

TOM (Third-party Opinion & Materials):
```
"Tomek mial dokładnie to samo i zobacz co się stalo..."
"Klienci często mówią to samo na początku..."
```

ED (Experience & Demonstration):
```
"Z mojego doświadczenia..."
"Pozwol że Ci pokaze..."
```

**KROK 9: TIE DOWN + TEST CLOSE**
```
"Ma to sens?"
"Widzisz jak to może zadziałać?"
"Czy to odpowiada na Twoje wątpliwości?"
```
--> Male TAK prowadzi do dużego TAK.

**KROK 10: ASSUMPTIVE CLOSE**
```
"Swietnie. Raty czy jednorazowo?"
"Który termin Ci pasuje?"
"Faktura na firmę?"
```
--> ZAKLADASZ że kupuje.
--> Nie pytaj "Czy chcesz kupić?" - nigdy!

### Integracja obiekcji z close

Po obsluzeniu obiekcji ZAWSZE wróć do close:

1. Po PARTNER --> Assumptive close: "Raty czy jednorazowo?"
2. Po PIENIADZE --> ROI close: "Jeden klient zwróci Ci koszt"
3. Po STRACH --> Social proof: "[konkretny dowód z opinii albo danych]"

Obiekcja obsłużona =/= sprzedaż zamknięta. Po każdym reframe --> ZAMYKAJ!

## PSYCHOLOGIA SPRZEDAŻY

### Master formula perswazji

#### Twin Forces (Dwie sily napedowe)

Ludzie kupuja z dwoch powodow:
1. **UNIKNAC BOLU** (silniejsze!)
2. **ZYSKAC PRZYJEMNOSC**

Kluczowa prawda: Ludzie zrobia WIĘCEJ żeby uniknąć bólu niz żeby zyskac przyjemność.

```
NIE WYSTARCZY że chca Twojego produktu.
Musza CZUC że NIE KUPIENIE będzie BOLESNE.

--> Przegapia okazje
--> Zostana w tyle
--> Beda sami
--> Straca
```

ZAWSZE SPRZEDAJESZ KONSEKWENCJE (Niebo i Pieklo)

#### Dickens Pattern

```
FIND THE WOUND --> OPEN THE WOUND --> HEAL THE WOUND
  (znajdz ból)    (otworz rane)    (ulecz produktem)
```

1. FIND - Znajdź ukryty ból (czesto nie są go swiadomi)
2. DISTURB - Zaburz ich komfort, pokaż konsekwencje
3. HEAL - Pokaz jak Twój produkt rozwiązuje problem

Jeśli masz problem z zamknięciem = nie stworzyłeś WYSTARCZAJĄCO DUŻO BOLU

#### ERBN vs DRAB

| ERBN | DRAB |
|------|------|
| Emotional Reasons to Buy NOW | Dominant Reasons to Avoid Buying |
| Emocjonalne powody do kupna TERAZ | Dominujace powody do NIE kupienia |
| Twoja robota: MAKSYMALIZUJ | Ich strachy: MINIMALIZUJ |

Twoja robota: Dac im więcej ERBN niz DRAB.

Jak? Zadawaj pytania które TWORZA BOL:
```
"Co się stanie jeśli nic nie zmienisz?"
"Ile Cię to kosztuje każdego miesiąca?"
"Jak długo jeszcze możesz sobie na to pozwolic?"
```

Jeśli emocje nie wystarczy --> dodaj LRBN (Logical Reasons to Buy Now)

### 9 narzędzi wpływu

#### 1. RAPPORT
Musza CZUC że jestes jak oni i że Ci zalezy.

Jak budowac:
- Wspolne zainteresowania
- Daj coś (reciprocation)
- Zadawaj pytania
- PO PROSTU SLUCHAJ
- Opowiedz historie
- Daj komplement (ale nie oczywisty!)

#### 2. DOBRE PYTANIA
Najlepszy przyjaciel sprzedawcy.

Cel: Odkryc motywacje i przekonania.
Bonus: Zdejmuja presje, pokazuja że Ci zalezy.

```
"Co jest dla Ciebie najważniejsze w [X]?"
"Co by się zmienilo gdybys to mial?"
"Co Cię powstrzymuje?"
```

#### 3. KONGRUENCJA (PEWNOSC)
Absolutna pewność = czysta moc.

```
Kupowanie = transfer emocji
Kto czuje wieksza pewność - TEN wplywa.
```

Musisz wierzyc że dajesz 10x więcej wartości niz bierzesz.

#### 4. ANCHORING (Kotwiczenie)
Sprzedaż = łączenie uczuć z produktem.
Twoja robota: połączyć ICH pożądane stany z TWOIM rozwiązaniem.
Połącz marchewke I kij.

#### 5. PATTERN INTERRUPTS
Czasem ludzie są "zamrozeni" w stanie. Gadanie to strata czasu.

Co robic: Zrob coś TOTALNIE nieoczekiwanego.
- Gdy maja obiekcję --> usmiechnij się szerzej
- Zmien temat radykalnie
- Rusz ich cialem

ALE: Rob to z zabawa i szacunkiem.

#### 6. NIESWIADOMA PERSWAZJA
Stan który popycha do akcji = NAPIECIE / PRESJA.

Narzedzia:
- Reciprocation (dalem --> oddaj)
- Contrast (porownanie)
- Commitment & Consistency (male TAK --> duze TAK)
- Double binds ("wolisz A czy B?")
- Pattern "because" (bo...)
- Social proof

#### 7. FRAMING (Ramowanie)

Co robimy = jak się czujemy = na czym się skupiamy
Zmien FOKUS --> zmienisz UCZUCIA --> zmienisz DZIALANIE.

**AS IF Frame** (Jakby)
```
Gdy mowia "nie moge/nie chce":
"Rozumiem. Ale GDYBYS to zrobił - co by się zmienilo?"
"Gdybys jednak kupil - co Cię przekonalo?"
```
--> Fokus na MOZLIWOSCI zmienia uczucia.

**PREFRAMING** (Przed)
```
Nie czekaj na obiekcję - ubij ja ZANIM się pojawi.
"Zanim powiem cenę - wiem że to inwestycja. I właśnie dlatego..."
```

**REFRAMING** (Zmiana)
```
Zamien obiekcję w pytanie:
"Za daleko" --> "Chodzi o odleglosc czy o CZAS dojazdu?"
--> Zmieniles fokus z odleglosci na czas.
```

**DEFRAMING** (Zniszczenie)
```
Totalnie ZNISZCZ ich frame. Używaj przy obiekcjach opartych na STRACHU.

Oni: "Nie możemy tego zrobić..."
Ty: "Wlasciwie ciesze się że to mowisz, bo szczerze -
    nie jestem pewien czy się kwalifikujesz do tej oferty..."

--> Nagle zamiast uciekac - gonia Cię.
```
UWAGA: Musisz być w 100% kongruentny i miec intensywnosc.

#### 8. TIME CONTROL
- 80% ONI mowia, 20% TY
- Eye contact = krytyczny
- Badz PRZED nimi codziennie proszac o zamówienia

#### 9. STATE MANAGEMENT
Musisz kontrolowac SWOJE emocje albo wszystko inne się sypie.

### Meta-Programs (Wzorce kupowania)

#### TOWARD vs AWAY
- TOWARD: Motywowani nagrodą (marchewka)
- AWAY: Motywowani strachem (kij)

Pytanie: "Co chcesz osiągnąć dzięki temu rozwiązaniu?"
Sluchaj jezyka!

#### INTERNAL vs EXTERNAL
- INTERNAL: Ocena wewnatrz (nienawidza gdy im mowisz co robic)
- EXTERNAL: Potrzebuja zewnetrznej walidacji

Pytanie: "Skąd wiesz że podjales dobra decyzje?"

Internal: "Nie wiem co jest dla Ciebie najlepsze. Ty jeden to wiesz. Co TY myslisz?"
External: "Jako ekspert powiem Ci - powinieneś użyć tego co inni już używają..."

#### POSSIBILITY vs NECESSITY
- POSSIBILITY: Widza możliwości (wybór, wolnosc)
- NECESSITY: Dzialaja gdy MUSZĄ (obowiazek, przymus)

Pytanie: "Dlaczego wybrałeś obecne rozwiązanie?"

Necessity: Pokaz BOL (musisz, powinieneś)
Possibility: Pokaz MOZLIWOSCI (możesz, wyobraz sobie)

#### SAMENESS vs DIFFERENCE
- MATCHERS: Szukaja podobienstw
- MISMATCHERS: Szukaja różnic (zawsze "ale...")

Dla hardcore mismatchera:
```
"Wiesz co, nie jestem pewien czy ta oferta jest dla Ciebie..."
--> Zaczna się sprzedawac SAMI.
```

#### GENERALITIES vs SPECIFICS
- Big picture: Najpierw ogół, potem szczegóły
- Specifics: Najpierw detale

Pytanie: "Wolisz najpierw poznac szczegóły czy ogólny obraz?"

### NWWAM - Framework kwalifikacji

Przed prezentacja MUSISZ znac:

| Litera | Co to | Pytanie |
|--------|-------|---------|
| N | Needs (Potrzeby) | "Co potrzebujesz osiągnąć?" |
| W | Wants (Pragnienia) | "Czego tak naprawde chcesz?" |
| W | Wounds (Rany) | "Co Cię boli w obecnej sytuacji?" |
| A | Authority (Decyzyjnosc) | "Kto podejmuje decyzje?" |
| M | Money (Pieniadze) | "Jaki masz budżet?" |

PLUS: Values (Wartosci), Beliefs (Przekonania), Buy Strategy (Jak kupuja)

UNDISTURBED prospects do NOT buy. Zrob ich ŚWIADOMYMI problemu. Sprzedaj im ich własny ból.

### 3 typy Test Close

**1. Opening Test Close** - na POCZĄTKU, sprawdź gdzie są.
```
"Jak długo rozważasz takie rozwiązanie?"
"Jak poważnie to rozważasz?"
"Dlaczego poważnie rozważasz takie rozwiązanie?"
```
--> Jeśli desire niski --> szukaj ukrytego bólu.

**2. Trade-off Test Close** - maja DRAB, skontruj z benefitem którego CHCA.
```
"OK, rozumiem że [DRAB]. Ale czy [BENEFIT] nie jest ważniejszy?"
```
--> Male zobowiazanie bez decyzji.

**3. Progressive Test Close (Future Pacing)**
```
"Wyobraz sobie że już to masz. Kiedy chcialbys zacząć?"
"Jak byś się czuł używając tego rozwiązania?"
```
--> Fokus na MOZLIWOSCI, zapominaja o negatywach.

ZASADA: Test close przez CAŁY proces. Zawsze wiedz gdzie są.

```
1. BIG FAT CLAIM - coś czego PRAGNA (oni, nie ty!)
2. ...BECAUSE... (bo...)
3. BACK IT UP WITH FACT (dowod)
4. "AND THIS MEANS TO YOU..." (benefit)
5. "WHICH REALLY MEANS TO YOU THAT..." (gleboki benefit)

```
